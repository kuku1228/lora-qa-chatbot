# LoRA 中文问答助手依赖（Python 3.10+）
#
# ⚠️ 安装顺序很重要，不要直接 pip install -r 这个文件：
#
#   第 1 步：先单独装 torch（必须走 PyTorch 官方源）
#       pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu124
#
#   第 2 步：再装其余依赖
#       pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#
#   第 3 步：验证（必须 True）
#       python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
#
# 为什么必须这样做：
#   1. PyPI 上的 torch 默认是 CPU 版，装不上 GPU；
#   2. 用 >= 约束时 pip 会拉最新版（实测拉到 torch 2.11 + CUDA 13），
#      而 AutoDL 常见驱动只到 CUDA 12.x，装完 torch.cuda.is_available() 为 False；
#   3. vLLM 0.8.5 依赖 torch 2.6.0 + CUDA 12.4，版本必须对齐，
#      否则 vLLM 装完也起不来（见 agent/serve_vllm.sh 里的说明）。
# ============================================================
